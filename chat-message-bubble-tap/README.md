# C8 Full Set · 이모지 2안 비교

`index.html` 또는 `handoff.html`을 열면 두 안을 비교할 수 있습니다.

- 1안: `demo-1.html` (기본 `demo.html`도 동일). 88종 중 한 종류를 균등 추첨해 같은 이모지 6개.
- 2안: `demo-2.html`. 서로 다른 두 종류를 균등 추첨해 각 3개씩, 총 6개. 방출 순서는 균등하게 섞습니다.
- 각 데모는 이미지·폰트·이모지·코드를 포함한 독립 HTML이며 다운로드 후에도 열 수 있습니다.
- 더블클릭·더블탭 시작에 결과를 고정합니다. 각 동작은 독립 재생하고 같은 결과가 다시 나올 수 있습니다.
- 문자를 코드 단위로 자르지 않아 표시 선택자(FE0F)가 보존됩니다. 중복·빈 항목을 제외하며 유효 후보가 1개면 그 문자 6개, 0개면 👍 6개입니다.

## 공통 모션

총 6개, 0.04초 간격, 터치 좌표 출발, 크기 26~42pt. 위 속도 기준 520×0.75~1.25, 옆 속도 ±170, 중력 1500, 초기 회전 ±8°, 회전 속도 ±30°/s. 화면 아래 끝+48을 지나면 제거합니다. 동작 줄이기에서는 탭 근처에서 0.6초 페이드 후 제거합니다. 말풍선별로 처음 12번의 더블클릭·더블탭에만 글자가 1pt씩 커집니다(16→28pt). 13회 이후에도 이모지는 계속 나오며 글자는 28pt를 유지합니다. 단일 클릭·탭은 이모지나 글자 확대를 일으키지 않습니다. 모바일은 같은 말풍선의 350ms 이내·24px 이내 두 탭을 한 동작으로 처리하며 스크롤·길게 누르기는 제외합니다. 키보드는 Enter 또는 Space를 350ms 안에 두 번 누릅니다.

1안 문자별 확률은 1/88, 2안 순서 없는 조합별 확률은 1/3828입니다. 두 안을 섞어서 추첨하지 않습니다.
전체 88종과 기계 판독 값은 `motion-spec.json`에 있습니다. 실제 앱 연결 및 최소 지원 OS별 이모지 가독성 검증은 별도입니다.
