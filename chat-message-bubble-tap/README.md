# 채팅 메시지 반응 — 확정 2안

서로 다른 이모지를 하나씩, 한 번에 총 2개 표시하는 개발용 소스입니다. 이모지 88종, 동작 코드, 화면 이미지와 글꼴, 모션 설정, 실행 예제를 포함합니다.

브라우저에서 실행하고 수정할 수 있는 JavaScript 소스입니다. 네이티브 앱은 모션 설정을 옮기고 기존 메시지 API·텍스트 렌더러·햅틱에 연결합니다. 웹뷰에서는 `src/bubble-tap.js`를 직접 사용할 수 있습니다. iOS·Android 설치용 라이브러리나 Lottie 파일은 포함하지 않습니다.

## 실행

Node.js 20 이상에서 이 폴더를 열고 실행합니다. 외부 패키지 설치는 필요 없습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. ES 모듈을 읽기 위해 HTML 파일 더블클릭 대신 로컬 서버를 사용합니다.

Python 3에서는 `python3 -m http.server 4173 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:4173/demo.html`을 열어도 됩니다.

검증은 `npm test`로 실행합니다. 이모지 3,828개 조합, 사용자별 5회, 메시지 12회, 본인 메시지 제외를 검사합니다.

## 파일

| 경로 | 용도 |
|---|---|
| `src/bubble-tap.js` | 독립 모션 렌더러와 탭 연결 함수 |
| `src/reaction.js` | 서로 다른 2개 추첨, 횟수 판정 |
| `src/config.js` | 코드에서 사용하는 이모지·모션 설정 |
| `src/demo.js` | 예제 연결, 임시 횟수 저장, 글자 확대 |
| `src/demo.css` | 채팅 화면과 모션 레이어 스타일 |
| `assets/` | 원본 PNG 4개와 WOFF2 글꼴 2개 |
| `motion-spec.json` | 네이티브 개발 전달용 모션 값·정책 |
| `INTEGRATION.md` | 앱 API·햅틱 연결 안내 |
| `demo.html` | 실행 예제 |
| `serve.mjs`, `package.json` | 외부 의존성 없는 로컬 실행 |
| `test/reaction.test.js` | 추첨과 횟수 경계 검사 |

화면 이미지는 시연용입니다. 실제 앱은 기존 UI·글꼴을 유지하고 모션을 연결하세요. 설정을 바꿀 때는 `motion-spec.json`을 수정하고 `npm run configure`로 `src/config.js`를 갱신합니다. `npm test`가 두 파일의 일치도 검사합니다.

## 반영한 동작

- 메시지를 한 번 누르면 서로 다른 이모지 2개가 0.04초 간격으로 나옵니다.
- 각 반응에서 두 종류는 중복 없이 균등 추첨합니다. 다음 반응에서 같은 조합이 다시 나올 수 있습니다.
- 사용자 한 명이 같은 메시지를 키울 수 있는 횟수는 최대 5회입니다. 본인 메시지는 제외합니다.
- 메시지 텍스트는 최대 12단계까지 커집니다. 기기별 기본 글자 크기를 고정하는 값은 전달하지 않습니다.
- 동작 줄이기 설정에서는 이동 없이 짧게 사라집니다.
- 웹 예제는 지원되는 브라우저에서만 진동을 시도합니다. iOS Safari 등 미지원 환경에서는 실제 햅틱이 나지 않습니다. 앱의 햅틱은 별도 콜백으로 연결합니다.

## 앱 연결 전에 확인할 정책

시연에서는 12회를 참여자 전체 누적으로 계산하고, 사용자별 5회 또는 메시지 12회 뒤 추가 모션·햅틱을 멈춥니다. **12회 합산 범위와 상한 뒤 효과 유지 여부는 앱 적용 전 확인할 정책입니다.** 확정된 서버 명세로 사용하지 마세요.

시연 횟수는 이 브라우저에만 저장합니다. 실제 API·다른 사용자와의 동기화는 포함하지 않습니다. ‘다시 체험’은 예제 데이터만 초기화합니다.

이미지와 글꼴은 제공된 채팅 시안에서 분리한 자산이며, 실제 앱에서는 프로젝트가 보유한 사용 권한을 따릅니다.
