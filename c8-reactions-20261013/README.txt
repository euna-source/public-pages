C8 응원 리액션 데모

index.html: 모든 버전 비교 + 직접 입력 즉시 미리보기
hands.html: 🙌 개별
rock.html: 🤘 개별
star.html: 🤩 개별
mix.html: 🙌 🤘 🤩 조합
fire.html: 🤘 🔥 🤩 조합
custom.html: 직접 입력 미리보기용

각 프리셋은 한 번 누르면 6개, 조합은 각 2개씩 나옵니다. 직접 입력은 최대 8개 이모지를 지원하며 피부색·국기·결합 이모지를 한 개로 취급합니다. 일반 글자는 제외합니다. 입력하면 자동 시연하고 말풍선을 누르면 다시 실행합니다. 7~8개 입력 시 모두 볼 수 있도록 입자 개수도 7~8개로 늘어납니다. 다시 보기로 글자 크기를 초기화합니다. 각 HTML은 인터넷 없이 열 수 있습니다.

근거: 같은 채팅 화면과 움직임으로 개별형·조합형·직접 입력을 비교하도록 구성했습니다.

추가 조합
awesome.html: 🤩🔥💯 — Awesome! 완전 인정
perfect.html: 😎👌💯 — Perfect! 딱 좋다
stage.html: 🤘🤩🔥 — 무대 찢었다!
8개 버튼을 가로로 나열하고 각 버튼 아래에 짧은 뜻을 표시합니다. 모바일에서는 가로로 넘겨 선택합니다.
근거: 이모지 모양과 의미를 같은 버튼 안에서 확인하며 선택하도록 설명을 붙였습니다.

직접 입력 후 [+]를 누르면 조합을 버튼으로 추가할 수 있습니다. 짧은 뜻은 선택사항입니다. 같은 조합은 중복 추가하지 않습니다. 추가한 조합은 해당 브라우저에 저장되며 다른 기기와 동기화되지 않습니다. 브라우저 데이터 삭제 시 저장 조합도 사라집니다.
저장한 버튼을 선택하면 하단의 저장 조합 삭제로 제거할 수 있습니다.
