01

정의

어떤 집단을 팀이라고 하는가

2명 이상의 크리에이터가 함께 작업물을 만들고, 팀으로서 그 작업물을 시장에 보여주는 집단

02

배경과 의도

왜 만드는가

크리에이터들이 C8 안에서 노크로 말을 걸고, 그룹 채팅으로 함께 작업을 하게됩니다.
그런데 함께 만든 작업물을 올릴 곳은 개인 프로필뿐입니다.

함께 만든 작업물이 팀의 이름으로 남을 자리가 필요합니다.

[참고] — Behance는 구성원과 작업을 팀 단위로 묶어 보여줍니다.

03

목표 · MVP

이번에 어디까지 하는가

오픈 스펙 — 팀 생성 · 팀 그룹채팅 · 팀 프로필 · 팀 포트폴리오

이번 버전에서 크리에이터는 앱 안에서 팀을 만들고, 팀원을 모으고, 자동으로 생긴 팀 채팅에서 대화를 나누고, 함께 만든 작업물을 팀의 이름으로 보여줍니다.

  • 팀 생성 — 팀 이름(영문 소문자 기준 중복체크) · 팀 프로필 사진 · 팀 한줄 소개를 입력 시 팀이 생성됩니다.

  • 팀 구성원 초대 — 팀원 이름을 검색해 초대합니다.

  • 팀 그룹채팅 — 팀을 새로 만들면 팀 전용 그룹채팅방이 함께 열립니다.

  • 팀 포트폴리오 — 팀원이 한 번 등록하면 팀 프로필과 참여한 팀원의 개인 프로필에 함께 게시됩니다.

  • 팀 프로필 — 팀을 새로 만들면 팀 프로필이 생성됩니다. 프로필은 팀 소개 · 팀 작업물 · 팀 구성원을 보여줍니다.

04

주요 사용자와 핵심 흐름

누가 어떻게 쓰는가

팀 생성(그룹채팅방 자동 생성) → 팀원 초대 → 합류 → 팀 포트폴리오 등록

팀 관리자가 팀을 만들면 전용 그룹채팅방이 함께 열리고, 이름 검색으로 초대받은 크리에이터가 팀원으로 합류해 포트폴리오를 등록합니다.
이미 프로젝트 채팅방에서 협업 중인 구성원은, 멤버가 정해진 시점에 채팅방에서 팀 프로필을 만들어 같은 흐름을 따릅니다. 이때 채팅방은 쓰던 방을 그대로 씁니다.

05

주요 기능

무엇을 개발하는가

역할

기능 · 흐름 순서

주요 요구사항

팀 관리자

① 팀 생성

  • 팀 이름 · 팀 프로필 사진 · 팀 한줄 소개 입력 → 팀 생성

  • 팀 이름은 한글 · 영문 · 이모지 허용, 중복 불가(영문 소문자 기준 중복 체크)

  • 생성과 동시에 팀 전용 그룹채팅방 개설

② 팀정보 관리

  • 팀 관리자(팀 생성자)만 팀 이름 · 팀 프로필 사진 · 팀 소개 수정 가능

③ 팀원 초대

  • 앱 내 크리에이터 이름 검색 → 초대, 인원 제한 없음

  • 거절한 크리에이터에게 다시 초대 가능, 초대 기한 없음

  • 팀 관리자만 팀원 내보내기 가능

팀원

④ 초대 알림

  • 앱 푸시, 앱 알림

⑤ 팀 합류

  • Chatty > [팀] 팀 초대 확인 → 수락 · 거절

공통

⑥ 팀 그룹채팅

  • 초대받은 팀원은 팀 채팅방에 자동으로 입장

  • 팀 관리자는 팀 해체하기 시 팀 해체되며

  • 팀 멤버는 팀에서 나가기 시 팀 채팅방에서도 자동으로 나가짐

  • 그 외 메세지 읽음처리, 채팅방 알림 설정, 메세지 복사 등은 채팅 공통 기준 따름

⑦ 팀 프로필

  • 팀 멤버는 초대 수락 시점에 자동으로 팀 팔로잉 됨

  • 팀 멤버 모두 팀 팔로잉을 해제 가능

  • 팀 관리자는 팀 정보 수정 및 팀 멤버 초대 가능

⑧ 팀 포트폴리오

  • 업로드 시점에 팀 포트폴리오를 선택해 등록 가능

  • 등록 후 개인 포폴 OR 다른 팀 포폴로 전환 가능

  • 등록 시점의 팀원 전체와 팀 프로필에 동시 게시

  • 공개 범위는 무조건 전체 공개

  • 수정 · 삭제는 업로드한 크리에이터만 가능

⑨ 팀 해체

  • 팀 관리자만 팀 프로필 수정화면에서 해체 가능

  • 팀 해체 시 팀 멤버는 2주간 팀 채팅방 읽기 전용으로 조회 가능

  • 팀 해체 시 팀 포트폴리오는 유지 (단! 팀 포폴에서 개인 포트폴리오로 수정 시 이전 팀 멤버 프로필 화면에서는 해당 팀 포폴 미 노출)

팀 나가기 · 팀 해체 · 회원 탈퇴 뒤의 노출 정책은 확정되어 있고, 상세는 개발 PRD가 담습니다.
