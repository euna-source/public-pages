왜 이 구성인가

  • 출발점은 반응이 확인된 게시물이에요: 2EZ 레퍼런스 모음(좋아요 522 · 댓글 60), 노트폴리오 「이번 주에 바이럴된 웹사이트」(13K · 댓글 283).
  • 도움: 장마다 사이트 하나, 검색어 하나, 언제 여는지 한 줄. 저장해 두면 바로 써먹어요.
  • 팔로우할 이유: 「CRE8OR PICKS 01」로 번호를 달고, 끝에 다음 분야를 댓글로 받아요.
  • 보낼 사람: 같이 작업하는 친구한테 「이거 저장해」. 받고 싶은 댓글: 「음악」「사진」 같은 분야 하나.
  • C8은 5장 「끼워넣기 한 번만 할게요」와 마지막 장 한 줄뿐이에요. 홍보 티는 웃고 넘어가요(2EZ 6장에서 빌림).

젠지가 직접 해 본 것

  • Cosmos: 「risograph poster」 검색 → 첫 화면이 전부 리소 포스터. 로그인 없이 둘러보기 됨, 메뉴 한국어.
  • Fonts In Use: 「hangul」 검색 → All (180), 한글 태그 175개. 둥켈산스·산돌 그레타산스 사례가 첫 줄에 나옴.
  • FILMGRAB: 「in the mood for love」 검색 → 화양연화 페이지, 장면 스틸 수십 장. 사이트 설명: 「참고와 교육 목적으로만 올린 이미지」.
  • Public Domain Review: 이미지 모음 첫 화면에 1907년 칼바흐 빈 공방 엽서. 저작권 끝난 작품을 다루고 글마다 권리 표시를 붙여요.
  • 위클리 베스트: 실제 이벤트 페이지(10/30)에서 「회원이면 신청 없이 참여」「작품·크리에이터 부문 각 1~10위」「폴더 속에 잠들어 있는 것도 괜찮아요」를 확인했어요.

올리기 전에 볼 것

  • 장 안 사이트 화면에는 남의 작업(포스터·영화 장면)이 보여요. 출처 사이트 이름을 장마다 적었지만, 캡처를 써도 될지는 올리기 전 확인이 필요해요.
  • 음악 분야 사이트는 못 넣었어요(후보 사이트가 자동 접속을 막아 직접 확인을 못 함). 첫 호는 디자인·영상·일러스트 넷이에요.
  • 5장 휴대폰 화면은 앱이 아니라 웹 이벤트 페이지 실제 캡처예요. 주차가 바뀌면 문구가 바뀔 수 있어요.
