베스트 크리에이터 선정 기준

작업을 올리고, 리스펙트와 대화를 나누고, 공유하며 프로필을 채운 크리에이터의 활동을 합산합니다.

항목내용
1회차팔로워 순증만 집계합니다. 포트폴리오·영감·리스펙트·채팅·공유·프로필 등 활동 점수는 모두 2회차부터 적용합니다.
2회차부터포트폴리오 40점, 영감·리스펙트 5점, 팔로워 10점, 채팅·공유 1점입니다.
프로필 소개항목당 10점, 6개 완성 시 60점입니다. 이미 작성한 내용도 인정합니다.
횟수 제한공유만 회차당 최대 10회입니다. 채팅·리스펙트 집계에는 상한이 없습니다.
동시 수상작품 부문과 크리에이터 부문의 동시 수상을 허용합니다.
미결 사항총점과 상대 그래프 중 앱 표시 방식, 동점 처리와 세부 집계 조건을 확인해야 합니다.

무엇을 세나요?

기간 안의 활동과 현재 프로필 소개 완성 상태를 함께 봅니다.

① 소통과 공유

리스펙트·메시지·공유 클릭

리스펙트는 횟수, 채팅은 메시지 건수로 셉니다. 같은 크리에이터에게 보낸 리스펙트도 매번 인정합니다.

② 작업과 소개

포트폴리오·영감·소개 완성

회차 안에 등록한 공개 작업과, 작성 시점에 관계없이 완성되어 있는 소개 항목을 셉니다.

③ 팔로워

회차 안에 늘어난 팔로워

전체 팔로워 수가 아닌 회차 안의 순증을 반영합니다.

집계하지 않는 행동

노크 보내기 자체, 받은 리스펙트, 조회·검색·북마크·체류 시간, 친구 초대로 생긴 가입 수는 활동 점수에 넣지 않습니다. 수락 후 열린 1:1 채팅과 그룹채팅의 메시지는 포함합니다. 공유하기 버튼 클릭은 별도 점수 항목입니다.

집계 기간과 배점

크리에이터 부문은 1회차(10/7~10/20)에 팔로워 순증만 집계합니다. 아래 활동 점수는 2회차(10/21~11/3)부터 적용합니다. 인기 포트폴리오 부문의 받은 리스펙트 기준은 유지합니다.

구분기준
집계 기간한 회차는 14일입니다. 수요일 00:00부터 둘째 화요일 23:59:59까지 집계합니다.
갱신매시 정각에 갱신하고, 마감 직후 배치를 운영 심사의 기준으로 사용합니다.
회차 변경활동 횟수는 새 회차에서 다시 셉니다. 프로필 소개는 완성 상태를 다시 반영하므로 이미 채운 회원이 0점으로 시작하지 않습니다.
팔로워 순증회차 시작과 집계 시점의 차이입니다. 같은 사람의 반복 팔로우는 중복 가산하지 않습니다. 기존 2회차 가안의 신규 계정 0.5명 보정은 별도 확인 사항입니다.
최종 상태창작물은 마감 시점에 전체공개로 남아 있어야 합니다. 프로필 소개의 내용 삭제도 현재 완성 상태에 반영합니다.

합산식

총점 = 포트폴리오 수 × 40 + 영감 글 수 × 5 + 팔로워 순증 × 10 + 리스펙트 횟수 × 5 + 채팅 메시지 수 + 공유 클릭 수(최대 10) + 완성한 소개 항목 수 × 10

총점에는 만점이 없습니다. 공유는 최대 10점, 프로필 소개는 최대 60점입니다.

완성한 항목 수 × 10점으로 계산합니다. 0개는 0점, 1개는 10점, 3개는 30점, 6개는 60점입니다. 완성률은 3개일 때 50%, 6개일 때 100%이며, 완성률 100%의 점수는 60점입니다.

이미 작성한 항목도 회차마다 인정합니다. 같은 항목에 학력이나 경력을 더하거나 문구를 고쳐도 항목당 10점을 넘지 않습니다. 항목별 필수 입력값은 개발과 확인합니다.

집계 원칙과 비정상 활동 대응

  • 채팅은 메시지마다, 리스펙트는 횟수마다 집계합니다. 서로 다른 크리에이터 수나 출석 일수로 바꾸어 세지 않습니다.
  • 공유는 버튼 클릭 시점을 셉니다. 외부 앱에서의 실제 전송·취소 여부는 점수 조건으로 쓰지 않습니다.
  • 소개 항목은 완성 상태에 대한 점수입니다. 작성·수정 횟수로 점수를 늘릴 수 없습니다.
  • 매크로·다중 계정 등 비정상 활동은 운영 확인 후 선정에서 제외할 수 있음을 안내합니다. 문제가 생기면 콘텐츠와 계정을 확인하고 신속히 대응합니다.
  • 복잡한 자동 차단·되돌림 횟수 제한은 초기 집계에 추가하지 않고 운영 결과를 보고 검토합니다.

삭제·취소와 제외 기준

집계값과 프로필 상태를 확인하고, 부정 참여는 운영 심사로 판단합니다.

상황처리
리스펙트 취소기존 취소분 제외 원칙에 따라 취소한 건당 5점을 뺍니다. 재전송 이벤트의 중복 처리 방법은 개발 확인 사항입니다.
언팔로우팔로워 순증에 반영합니다. 음수 처리와 신규 계정 보정은 상세 산식 확인 사항입니다.
작업 삭제·비공개해당 포트폴리오·영감 글 점수를 제외합니다. 프로필과 작업의 기존 공개 자격 조건은 유지합니다.
소개 항목이 비어 있음그 항목은 0점입니다. 완성한 항목 수를 다시 계산하며 기존에 얻은 10점을 누적 보유하지 않습니다.
공유 시트에서 취소공유 버튼 클릭 이후 외부 전송·취소를 판별하지 않으므로 클릭 점수를 차감하지 않습니다.
비정상 활동 확인매크로·다중 계정·반응 교환·도용 등이 확인되면 선정에서 제외할 수 있습니다. 발표 뒤 확인되면 선정이 취소될 수 있습니다.

기존 통지·소명·이의 신청 절차는 유지합니다. 채팅 삭제 시점의 집계 처리와 동점 처리 등 미정 사항은 아래에서 별도로 확인합니다.

운영 후 검토할 내용

우선 단순한 기준으로 운영하고, 초기 회차의 실제 기록으로 조정 필요성을 판단합니다. 변경은 다음 회차 시작 전에 안내합니다.

  • 채팅이 총점에서 차지하는 비중과 상위권 활동 구성을 확인합니다.
  • 공유 클릭 기록을 먼저 쌓고, 실제 유입을 확인하는 레퍼럴·UTM 추적은 추후 검토합니다. 회의에서는 추적 정보 보존을 위해 링크 단축을 적용하지 않기로 했습니다.
  • 복잡한 어뷰징 방지 규칙과 보상 조정은 사용자 활동과 운영 부담을 확인한 뒤 검토합니다.
추후 검토 항목

팀 신규 멤버, 프로젝트 카드 등록과 신규 지원자 점수는 현재 집계·안내 조건에서 제외합니다. 도입 여부와 배점은 아직 정하지 않았습니다. 이전 MAU 단계별 배점·보상안은 현재 적용 규칙이 아닙니다.

앱 화면 노출 범위

세부 배점은 비공개입니다. 활동 총점을 그대로 보여줄지, 상대적인 격차를 그래프로 보여줄지는 미정입니다.

위치표시 기준
순위표순위와 활동명을 표시합니다. 활동 총점·상대 그래프의 표시 방식은 별도 결정합니다.
내 활동내 순위를 안내합니다. 총점 표시 여부는 순위표와 함께 정합니다.
기준 안내리스펙트·대화·공유·작업 등록·소개 완성·팔로워 증가가 반영된다는 행동 안내를 제공합니다. 항목별 배점표는 공개하지 않습니다.
운영 자료항목별 횟수·완성 상태·점수와 합계 등 판단 근거를 보관합니다.

참가자 안내 문구

회차에 맞는 안내만 사용합니다.

1회차

크리에이터 부문은 이번 회차에 늘어난 팔로워 수로 순위를 정해요.

2회차부터

리스펙트 보내기, 채팅방 대화, 공유하기, 포트폴리오와 영감 올리기, 프로필 소개 채우기가 활동에 반영돼요. 회차 동안 늘어난 팔로워도 함께 봐요.

이미 작성한 프로필 소개도 반영돼요. 공유하기는 회차마다 최대 10회까지 인정해요.

매크로 등 비정상적인 활동, 여러 계정 사용, 리스펙트나 팔로우 교환 요청, 타인 작품 도용이 확인되면 순위에서 제외되며, 발표 뒤에 확인되면 선정이 취소될 수 있습니다. 규칙 변경은 다음 회차 시작 전에 안내합니다.

개발 확인과 남은 결정

항목확인할 내용
소개 완성 판정각 항목에서 무엇을 채워야 완성인지, 공개 설정과 상태 조회가 가능한지 확인합니다. 학력·경력이 여러 개여도 항목당 최대 10점입니다.
이벤트 기록메시지 전송·공유 클릭·리스펙트 이벤트의 시간과 식별값을 확인합니다. 같은 이벤트의 통신 재시도를 별도 행동으로 세지 않도록 확인합니다.
팔로워 상세기존 2회차 가안의 신규 계정 0.5명 보정과 음수 순증 처리 여부를 확인합니다. 1회차에는 비공개 가중 보정을 적용하지 않습니다.
취소·삭제리스펙트 취소 후 재전송, 삭제된 채팅의 점수 처리와 프로필 집계 시점을 확정합니다.
동점 처리기존 고유 인원 기준과 변경된 횟수 기준을 대조해 확정합니다. 미정 규칙을 자동 적용하지 않습니다.
앱 표시 방식활동 총점 공개 또는 상대 그래프 표시를 결정합니다. 세부 배점 비공개는 유지합니다.
집계 가능 여부회의에서 공유 API 호출을 확인했으나 이번 작업에서는 서버 구현·실제 로그를 검증하지 않았습니다. 시행 전 각 항목 기록과 배치 결과를 대조합니다.

현재 배점은 9/23 회의와 후속 선정 기준 변경을 반영했습니다. 기존 외부 사례 조사는 이전 제안의 참고 자료이며, 현재 배점의 효과를 검증한 결과는 아닙니다.
