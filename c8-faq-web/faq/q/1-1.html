가입은 어떻게 하나요?

앱 첫 화면에서 Kakao·Google·Apple·E-mail 가운데 하나를 골라 가입해요. 가입과 로그인은 같은 화면에서 시작해요.

E-mail로 가입할 때는 아래 순서를 거쳐요.

  1. 이메일 입력
  2. 약관 동의
  3. 이메일 인증
  4. 비밀번호(확인 입력 포함)
  5. 사용자 ID
  6. 활동명

Kakao·Google·Apple로 가입하면 약관 동의 → 사용자 ID → 활동명만 거쳐요. 이메일 인증과 비밀번호 단계는 없어요.

가입을 마치면 바로 로그인돼요. 작업을 올리려면 먼저 프로필 커버를 등록해야 해요. 올리기를 누르면 안내가 나오고, 거기서 「커버 등록하기」를 누르면 「My」의 커버 템플릿 선택으로 가요.
