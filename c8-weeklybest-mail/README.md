# 위클리 베스트 메일 편집기

기본 문자 안내와 1:1 채팅 안내 포함 버전을 선택하고, 주차별 시트의 지급대상자를 골라 수상 안내 메일을 만듭니다. 메일은 자동 발송하지 않습니다.

## 사용 방법

1. 편집기에서 ‘주차 메일 가져오기’를 누릅니다. 회사 Google 계정으로 로그인된 브라우저가 당첨자 관리 시트 전체를 xlsx 파일로 내려받습니다.
2. 받은 파일을 ‘주차별 메일 만들기’ 칸에 끌어 놓거나 ‘받은 파일 선택’으로 고릅니다. 주차별 탭이 한 번에 모두 들어옵니다.
3. 주차와 지급 대상자를 고르고 ‘선택한 분의 메일 만들기’를 누릅니다.
4. ‘공통 안내 버전’에서 기본 또는 1:1 채팅 안내 포함을 선택합니다. 이름·수상 내역·금액을 확인하고 메일 제목과 본문을 복사합니다.

‘다른 방법으로 가져오기’에는 북마크(시트 주차 탭에서 눌러 한 주차만 새 편집기 창으로 전달), 주차별 CSV 파일, 시트 복사·붙여넣기가 남아 있습니다. 북마크는 북마크 막대에 저장해야 동작하므로 기본 경로에서 뺐습니다(2026-11-09). 시트를 수정한 뒤에는 다시 가져와야 합니다. 시트에 이메일·휴대폰 번호 열이 없으므로 이메일 주소나 연락처 유무를 자동 판정하지 않습니다.

xlsx 읽기는 같은 폴더의 `xlsx.mini.min.js`(SheetJS 0.20.3, cdn.sheetjs.com 배포본)를 파일을 고를 때만 불러옵니다.

## 보관과 검증

시트는 비공개로 유지합니다. 원본 시트는 읽기만 하며, 가져온 명단과 메일 초안은 현재 편집기 창에만 저장하고 창을 닫으면 지웁니다. ‘가져온 명단 지우기’로 명단과 현재 초안을 삭제할 수 있습니다. 공개 배포 파일에는 실제 수령인 명단을 포함하지 않습니다.

사람별 관리표에서 ‘지급대상’인 사람만 포함합니다. ‘당첨 안내’ 상태와 별개로 선택합니다. 순위별 금액, 부문별 금액, 상품권별 금액과 총합이 일치하지 않으면 가져오기를 중단합니다.

검증: `node --test sheet.test.cjs`
