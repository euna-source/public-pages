# 실제 화면으로 따라가는 사용자 여정

아래는 대표적인 이용 경로입니다. 모든 화면을 반드시 순서대로 방문한다는 뜻은 아닙니다. 로그인 상태·회원 권한·등록 상태에 따라 갈라집니다.

## 처음 가입하고 들어오기

신규 이메일 가입의 앱 내 화면 순서입니다. 소셜 가입은 이메일 인증·비밀번호 단계를 건너뜁니다.

`앱 실행 · 시작 화면` → `로그인 · 시작` → `로그인 · 이메일 입력` → `회원가입 · 약관 동의` → `회원가입 · 이메일 인증` → `회원가입 · 비밀번호 설정` → `회원가입 · ID 입력` → `회원가입 · 이름 입력`

가입 성공은 액션입니다. 이후 권한·튜토리얼 표시 조건에 따라 첫 이용 화면으로 이어집니다. 가입 후 로그인 화면을 다시 필수로 거치지 않습니다.

## 가입 후 첫 이용

AOS 신규 가입의 대표 경로입니다. iOS는 튜토리얼·권한 조건에 따라 순서와 표시 여부가 다릅니다.

`첫 이용 · 권한 안내` → `첫 이용 · 서비스 안내` → `첫 이용 · 환영 영상` → `디스커버리 · 발견`

안내 건너뛰기·기존 동의·보존된 딥링크가 있으면 실제로 표시된 화면만 기록합니다. 디스커버리 도착을 무조건 가정하지 않습니다.

## 다시 로그인하고 탐색하기

로그인이 풀린 기존 이메일 회원의 경로입니다. 로그인 상태가 유지되면 인증 화면을 생략합니다.

`앱 실행 · 시작 화면` → `로그인 · 시작` → `로그인 · 이메일 입력` → `로그인 · 비밀번호 입력` → `로그인 · 2단계 인증` (조건부) → `디스커버리 · 발견`

2단계 인증은 필요한 회원에게만 표시합니다. 로그인 성공은 별도 화면이 아닙니다.

## 작업물을 발견하고 사람에게 연결하기

발견과 검색에서 같은 상세 화면으로 이어집니다. 진입 경로가 달라도 상세 화면 이름은 유지합니다.

`디스커버리 · 발견` → `포트폴리오 · 상세` → `크리에이터 · 프로필` → `크리에이터 · 포트폴리오` → `대화 시작 · 목적 선택` (조건부) → `채티 · 1:1 대화`

노크 화면은 플랫폼·관계 상태에 따라 목적 선택 또는 메시지 입력입니다. 이미 대화 중이면 대화방으로 바로 이동할 수 있습니다.

## 파인더에서 크리에이터 찾기

검색→결과→조건 조정→프로필 순서로 실제 보이는 목적지를 기록합니다.

`파인더 · 검색` → `파인더 · 크리에이터 검색 결과` → `파인더 · 크리에이터 필터` → `파인더 · 크리에이터 검색 결과` → `크리에이터 · 프로필`

필터 값을 바꾸는 행위는 화면이 아닙니다. 필터 화면을 열고 결과로 돌아오는 방문을 구분합니다.

## 내 프로필을 등록하고 수정하기

마이에서 자기표현을 준비합니다. 아래 화면들은 필요한 등록 항목을 선택할 때 열리며 모든 회원의 필수 순서는 아닙니다.

`마이 · 프로필` → `프로필 등록 · 커버 스타일 선택` → `프로필 등록 · 커버 정보 입력` → `마이 · 프로필` → `프로필 등록 · 자기소개 입력` → `커리어 · 이력 관리` → `커리어 · 경력 입력` → `마이 · 프로필`

커버·자기소개 폼 안 입력 필드는 같은 화면입니다. 등록 이력에 따라 첫 마이 대신 커버 선택이 먼저 보일 수 있습니다.

## 포트폴리오를 올리고 확인하기

작업물 등록부터 첨부 편집, 내 목록에서 결과 확인까지의 대표 경로입니다.

`마이 · 포트폴리오` → `작업물 등록 · 종류 선택` (조건부) → `포트폴리오 · 작성` → `첨부 · 이미지 자르기` (조건부) → `포트폴리오 · 작성` → `마이 · 포트폴리오` → `포트폴리오 · 상세`

종류 선택·이미지 편집은 실제 열린 경우만 기록합니다. 저장 후 도착지는 실제 앱 이동을 따르며 완료 액션을 가상의 화면으로 만들지 않습니다.

## 프로젝트에 참여해 협업하기

프로젝트를 발견하고 신청한 뒤 대화로 이어지는 흐름입니다.

`파인더 · 프로젝트 검색 결과` → `프로젝트 · 상세` → `프로젝트 · 참여 신청` (조건부) → `채티 · 프로젝트 대화 목록` → `채티 · 프로젝트 대화`

지원 수락과 대화방 진입은 관계·권한에 따라 달라집니다. 이 경로는 가능한 여정이며 즉시 자동 이동을 뜻하지 않습니다.

## 팀을 만들고 함께 작업하기

팀 정보 등록과 멤버 초대, 팀 작업물·대화로 이어집니다.

`팀 · 내 팀과 초대` → `팀 · 정보 입력` → `팀 · 포트폴리오` → `팀 · 멤버` → `팀 · 멤버 초대` (조건부) → `채티 · 팀 대화`

팀 정보 편집과 초대는 권한이 있을 때만 가능합니다. 같은 팀 프로필의 호스트와 선택 탭을 동시에 기록하지 않습니다.
