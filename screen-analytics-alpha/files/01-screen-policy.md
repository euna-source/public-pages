# 같은 화면을 같은 기준으로 세는 규칙

화면 이름은 사용자에게 보이는 주요 목적지를 나타냅니다. 클래스 이름, URL의 개별 사용자 번호, 번역된 제목이 달라져도 같은 목적과 내용을 가진 화면에는 같은 분석 이름을 사용합니다. 한국어 화면명은 사람이 읽는 표시명이고, 영문 이름은 데이터에 기록하는 고정값입니다.

팀 목록은 `team_list`, 검색 결과의 크리에이터 탭은 `finder_result_creator`입니다. 내 프로필과 타인 프로필을 함께 비교할 때는 `profile_home`으로 묶되, 주체와 표현 방식을 함께 기록해 각각의 통계도 유지합니다. 정의 목록에 있는 이름만 발신하고, 이름이 정해지지 않은 값을 홈으로 대신 보내지 않습니다.

| 결정 | 적용 규칙 |
|---|---|
| 이름 형식 | 영문 소문자와 밑줄로 구성하고 40자 이내로 관리합니다. 이 길이는 팀의 관리 규칙입니다. 화면 제목의 번역·문구 변경으로 키를 바꾸지 않습니다. |
| 화면 1회 조회 | 사용자가 볼 수 있는 주 목적지로 전환되고 표시 준비가 끝난 때 한 번 기록합니다. 로딩만 하거나 옆 화면을 미리 준비한 상태는 제외합니다. |
| 빈 화면·오류 | 데이터가 없는 정상 결과는 원래 화면 이름과 `content_state=empty`로 기록합니다. 독립 오류 화면으로 전환되면 그 오류 화면을 기록합니다. 재조회 오류 알림만 뜬 경우 원래 화면 조회를 추가하지 않습니다. |
| 탭 | 검색 결과 유형과 연락처의 일촌·팔로워·팔로잉처럼 목적이 다른 주 탭은 각각 이름을 갖습니다. 탭을 담는 부모 컨테이너를 동시에 세지 않습니다. |
| 단계형 작성 | 같은 작성 과업의 세부 단계는 `flow_step_view`와 `step_name`으로 분석합니다. 목록에서 별도 목적지로 정의한 단계만 새로운 화면 조회를 올립니다. |
| 팝업 | 토스트·단순 확인창·부분 목록은 화면 조회에 포함하지 않습니다. 노크 목적 선택·리스펙트 메시지 선택처럼 전면에서 독립 과업을 수행하는 표면은 별도 화면으로 정의합니다. |
| 같은 키에서 대상 변경 | 콘텐츠 상세를 다음 콘텐츠로 넘기거나 다른 사람의 프로필을 열면 새 방문으로 기록합니다. 스크롤·재렌더·같은 대상 재요청은 새 방문이 아닙니다. |
| 뒤로 가기 | 실제로 이전 목적지가 다시 보이면 새 방문으로 기록합니다. 복귀 원인은 `navigation_type=back`으로 남깁니다. |
| 앱·브라우저 복귀 | 목적지가 그대로면 같은 방문을 유지하고 `screen_resume`을 기록합니다. 백그라운드 시간은 체류에서 제외합니다. 프로세스가 종료돼 다시 시작했다면 새 방문입니다. |
| 웹뷰 | 네이티브는 보임·가려짐·주 화면 여부를 Web에 알려 줍니다. Web 화면의 방문 결정은 Web이 하고, 웹뷰의 전달은 네이티브 수집기로 통일하는 방식을 제안합니다. 앱 호스트와 Web이 각각 GA 조회를 보내지 않습니다. |
| 내장 웹 모듈 | 홈 안의 퀴즈·전광판·태그클라우드 등은 홈을 대체하지 않으면 화면으로 세지 않습니다. 모듈 노출·선택 이벤트로 분석합니다. |
| 시스템 UI·QA | OS 사진 선택기·공유 시트와 내부 QA 도구는 제품 화면 방문 수에서 제외합니다. 진입·결과가 필요하면 별도 행동 또는 진단 이벤트를 사용합니다. |
| 레거시 | 경로가 남아 있어도 실제 알파 진입이 확인되지 않은 캐스팅·클럽 화면은 보류 표시를 유지합니다. 삭제나 활성 전환은 진입 근거 확인 후 판단합니다. |

프로필은 주체를 `profile_owner=self|other`, 표현을 `view_mode=card|resume`으로 구분합니다. 실제로 독립된 소개·작품 탭으로 전환하면 목록에 정의한 해당 탭 이름을 사용하고 프로필 부모 조회를 동시에 기록하지 않습니다. Web 페이지 안에서 단순히 소개 영역으로 스크롤한 경우는 새 화면 조회가 아닙니다.

갤러리의 인트로·작품 설명·아웃트로는 한 갤러리 안의 상태로 관리합니다. `gallery_phase_change`로 단계 이동을 남기며, 화면 방문은 `gallery_home`으로 셉니다. 인맥 다이얼은 팔로우가 부족한 안내, 본인 다이얼, 다른 사람의 인맥 탐색을 구분하되, 같은 화면의 애니메이션은 조회로 추가하지 않습니다.

조회 수는 정규화된 방문 이벤트 수입니다. 방문 사용자 수는 합의된 사용자 식별 기준으로 계산하고 플랫폼별 사용자를 단순 합산하지 않습니다. 체류시간은 실제 전면 노출 구간의 합으로 계산하며, 종료 기록이 없는 방문의 체류시간을 임의로 채우지 않습니다. 작성 완료·중단 로그는 전환 지표이며 화면 조회 수에 더하지 않습니다.

이 규칙을 적용하려면 이전과 새로운 집계를 구분하는 정의 버전이 필요합니다. 단계 합치기, 컨테이너 제거, 복귀 처리 변경으로 조회 수가 달라질 수 있으므로 이전 값 대응만으로 과거 통계가 완전히 같아지는 것은 아닙니다. 적용 전후 비교는 같은 정의 버전 또는 검증된 변환 범위에서 수행합니다.
