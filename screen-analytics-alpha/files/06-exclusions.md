# 화면에서 제외하거나 확인을 보류한 항목

화면이 아닌 항목은 이름을 보내지 않습니다. 조건부 후보는 실제 알파에서 진입을 확인하기 전 본문 화면 정의에 포함하지 않습니다.

## 화면이 아닌 항목

| 이전 항목 | 판단 |
|---|---|
| 채티 | 채티의 실제 선택 목록 하나만 기록합니다. 루트 컨테이너는 별도 화면이 아닙니다. |
| 검색 결과 | 크리에이터·포트폴리오·프로젝트 중 실제 선택된 결과 탭 하나만 기록합니다. |
| 인맥 관리 | 인맥의 실제 관계 목록 탭 하나만 기록합니다. |
| 북마크한 콘텐츠 | 북마크의 실제 크리에이터·포트폴리오 탭 하나만 기록합니다. |
| 팀 프로필 | 팀 소개·포트폴리오·멤버 중 실제 전면 탭 하나만 기록합니다. |
| 1촌 요청 목록 | 일촌 목록 안 요청 구역이면 별도 화면이 아닙니다. 독립 요청 목록이 생기면 그때 정의를 추가합니다. |
| 갤러리 · 인트로·준비 | 갤러리 로딩·인트로 상태입니다. 갤러리 화면의 상태값으로 관리합니다. |
| 갤러리 · 작품 설명 | 갤러리 작품 설명의 펼침 상태입니다. 독립 목적지로 확인되지 않아 화면명을 분리하지 않습니다. |
| 갤러리 · 아웃트로 | 갤러리 종료 상태입니다. 갤러리 화면의 상태값으로 관리합니다. |
| 발견 · OX 퀴즈 모듈 | 디스커버리 피드 사이의 작은 WebView 슬롯입니다. URL이 있어도 독립 화면으로 세지 않으며 디스커버리 화면 제목을 유지합니다. |
| 발견 · 태그 클라우드 모듈 | 디스커버리 피드 사이의 작은 WebView 슬롯입니다. URL이 있어도 독립 화면으로 세지 않으며 디스커버리 화면 제목을 유지합니다. |
| 발견 · 전광판 모듈 | 디스커버리 피드 사이의 작은 WebView 슬롯입니다. URL이 있어도 독립 화면으로 세지 않으며 디스커버리 화면 제목을 유지합니다. |
| 프로필 사진 · 시스템 선택기 연결 | 시스템 사진 선택기와 진행 상태를 연결하는 호스트입니다. 앱의 독립 화면으로 기록하지 않습니다. |
