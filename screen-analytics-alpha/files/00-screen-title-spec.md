# 사용자 흐름에 따른 GA 화면명 정의

이 문서는 사용자가 지금 어느 화면에 있는지를 GA에서 같은 이름으로 읽기 위한 화면 정의서입니다. 앱 실행·가입·로그인부터 발견, 검색, 내 프로필 등록, 타인 탐색, 소통과 협업까지 화면 단위로 정리했습니다.

각 행의 ‘GA 화면 제목’은 그대로 수집할 고정값입니다. ‘개발 키’는 구현과 목록 관리를 위한 영문 식별값입니다. 한국어 제목을 GA 표시값으로 사용하는 안을 기본으로 작성했으며, 표시 언어는 팀 적용 전에 확정합니다.

| 화면 | GA 화면 제목 | 개발 키 |
|---|---|---|
| 신규 회원이 이름을 입력 | 회원가입 · 이름 입력 | auth_signup_name |
| 추천 피드에서 탐색 | 디스커버리 · 발견 | home_discovery |
| 크리에이터 검색 결과 확인 | 파인더 · 크리에이터 검색 결과 | finder_result_creator |
| 내 포트폴리오 목록 확인 | 마이 · 포트폴리오 | my_portfolios |
| 다른 사람의 포트폴리오 목록 확인 | 크리에이터 · 포트폴리오 | creator_portfolios |
| 하나의 포트폴리오 상세 열람 | 포트폴리오 · 상세 | portfolio_detail |
| 프로젝트 대화방에서 소통 | 채티 · 프로젝트 대화 | chat_project_room |

## 무엇을 한 화면으로 정하는가

사용자가 전면에서 읽거나 입력하는 목적지가 한 화면입니다. 전체 페이지뿐 아니라 목록이 바뀌는 탭과 독립적인 선택·입력 과업을 수행하는 시트도 포함합니다. 같은 목적지의 로딩·빈 결과·오류 문구·입력 칸·키보드·버튼 클릭은 별도 화면이 아닙니다.

마이와 타인 프로필은 소유자와 가능한 과업이 달라 구분합니다. 반면 같은 포트폴리오 상세에 디스커버리·파인더·프로필 중 어디서 들어왔는지는 진입 속성으로 구분하고 화면 이름은 유지합니다. 화면에 보이는 회원명·검색어·콘텐츠 제목·고유번호는 화면 제목에 붙이지 않습니다.

## 수집 필드

| 환경 | 이벤트 | 이 정의서의 제목을 넣는 필드 |
|---|---|---|
| iOS·AOS 앱 | screen_view | screen_name |
| 앱 안 WebView | 호스트 앱의 screen_view | screen_name. 앱·WebView에서 같은 화면을 두 번 전송하지 않음 |
| 독립 웹 브라우저 | page_view | page_title |

앱 화면명은 Firebase의 `screen_name`, 웹 페이지 제목은 `page_title`로 설정합니다. GA의 ‘페이지 제목 및 화면 이름’ 차원에서 두 환경을 같은 제목으로 읽습니다. `screen_title`이라는 공통 기본 필드가 따로 있다고 가정하지 않습니다. [Firebase 화면 조회 문서](https://firebase.google.com/docs/analytics/screenviews), [GA 페이지 및 화면 보고서](https://support.google.com/analytics/answer/12926732?hl=ko).

`screen_key`와 `screen_definition_version`은 별도 관리 값입니다. GA에서도 키를 검색하려면 필요한 사용자 정의 차원으로 등록하고, 제목 변경 시에는 동일 키와 정의 버전으로 변경 이력을 연결합니다.

## 적용 범위

기준은 2026년 9월 9일 고정한 AOS 3.1.0·iOS 3.0.2·Front Web의 알파 후보 소스입니다. 화면 제목은 이번 정의이며 현재 이미 이 이름으로 수집된다는 뜻이 아닙니다. 실제 알파 배포와 설치본의 일치, GA 수신 확인은 남아 있습니다.

이전 화면 분석 목록은 근거 자료로 사용했습니다. 레거시·조건부 진입과 화면이 아닌 항목은 본문 화면 정의에서 분리했습니다. 특정 화면의 플랫폼 표시는 소스 근거가 있는 구현 환경이며 모든 사용자에게 해당 화면이 노출된다는 뜻은 아닙니다.
