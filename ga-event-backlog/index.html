이름표에서 뺀 것들.

GA 통합 화면 이름표는 "화면이 열렸다"만 셉니다. 여기 모은 항목은 화면 조회가 아니라 사용자 행동·상태 변화라서 그 이름표에서 빠졌지만, 놓치면 안 되는 것들입니다 — 제품 판단으로 중요도가 높거나, 이미 화면에서 행동으로 재분류된 것들입니다. 이름·트리거·파라미터는 아직 설계 전입니다.

화면 목록을 만들다가 발견했지만, 화면이 아니라 이 페이지로 옮긴 항목입니다.

tag_cloud 중요도 높음

웹 제안 이름 · Discovery 피드 안 임베디드 모듈 · 2026-09-14 웹팀 발견

디스커버리 피드 사이에 얹히는 태그 클라우드 — 한 분류의 키워드를 뿌려 고르게 하고, 고른 값을 서버에 저장합니다. 제품상 중요한 영역이지만 피드 스크롤마다 여러 번 나타나는 슬롯이라, 화면 조회로 세면 세션당 화면수·이탈률 같은 기본 지표가 깨집니다(웹팀 경고).

  • 왜 화면이 아닌가 — 전체 화면 전환이 아니라 피드 안 한 슬롯이 채워지는 것. 스크롤할 때마다 여러 번 노출될 수 있음.
  • 설계해야 할 이벤트(안) — tag_cloud_impression{type}(노출) · tag_cloud_select{keyword}(선택) · tag_cloud_save{keyword}(저장 완료)
  • 출처 — c8c-web 화면 목록 No.16, src/pages/discovery/tag-cloud/index.tsx

화면 → 행동으로 재분류된 것 (참고)
