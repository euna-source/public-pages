# Section mapping and behavior
| 섹션 | 정보 | 문법 | 패밀리 |
|---|---|---|---|
| 공간 탐색 | 두 세계·원탁·서가의 위치 | 큰 fal 이미지 + 선택 지점 + 맥락 패널 | DISTRIBUTION |
| 역할 | 누가 책임지는가 | 캐릭터와 담당의 짧은 목록 | TABLE |
| 한 업무의 흐름 | 병렬 협업·회의·인계·학습 | 단계 전환 + 동시에 진행되는 갈래 | FLOW |
| 아젠다 | 지난 판단·새 근거·다음 질문 | 이어지는 결정 기록 | TIME |
| 근거 | 연구→아이디어→적용 | 출처가 붙은 대응표 | RELATION |
정적 HTML/CSS/JS. 기존 무채색 구조와 숲색 강조 유지. 수치 대시보드의 KPI/차트를 억지로 넣지 않음: 사용자 요청의 공간과 역할 관계를 먼저 보여준다. 이미지 확대 dialog, 키보드·모바일 영역 목록, 상태 선택·다음 단계 버튼은 실제 동작. 예시 상태는 실제 LLM·워크플로 실행을 주장하지 않음.

입체 공간 확장: 전폭 캔버스와 바로 아래 시점/정지/자동 진행 조작, 캐릭터별 현재 행동과 가까이 보기 목록, 영역 설명 패널을 사용한다. 9개 독립 인물과 3명 회의 대표를 구분한다. 같은 공간 안에서 경로·손의 소품·시선·눈·귀·업무 자세가 상태에 맞게 바뀐다. 초기 로딩·WebGL/자산 실패·JavaScript 비활성은 정적 시안으로 이어진다. 움직임 줄이기와 정지 중에도 단계/카메라는 조작한다. 확대 창은 캔버스를 복제하지 않고 이동한다. 모바일은 모든 조작44px, 전체공간이 잘리지 않는시점과 각자확대접근을 보존한다.

연기 개정: 기존 작업·정지·카메라 조작 아래에 여섯 개의 짧은 장면을 추가한다. 눌렀을 때 담당 인물과 표정·동작으로 바로 연결하며, 정지 중에는 해당 포즈를 보여 준다. 바닥 동작 도중 단계 전환은 자세 회복을 마친 뒤 새 업무로 잇는다. 공간은 기존 크림·목재·숲색과 아치/원탁/서가 관계를 보존하고, 사용 중인 소품·천·식물·창빛으로 밀도를 높인다. 기술적인 조명·관절 설정은 제품 화면에 노출하지 않는다.
