# Design brief
사용자: 샐리. 60초 내 이 공간에서 누가 무엇을 하고 어떤 변화가 생겼는지 이해한다.
승인된 방향: 지브리·산리오 두 세계, 모든 기존 캐릭터 외형 유지, 45도 입체 시점, 하울 지식총괄, 담당자 분신 병렬·자율 발견·실행, 초코캣 독립 관찰·개선, 자동회의와 지속 아젠다.
이번 산출: 실제 fal 이미지와 클릭 가능한 공간·예시 업무 흐름을 가진 설계 체험 보드. 실제 운영 상태로 가장하지 않는다.
말투: 짧고 편안한 한국어. 읽어야 할 정보는 행동과 이유 중심. 내부 프롬프트·개인 세션·로컬 경로를 공개 화면에 싣지 않는다.
화면: 기존 크림·숲 초록·Pretendard 계승. 캐릭터의 색은 원본 유지. 하나의 큰 공간 이미지와 옆의 맥락 패널, 선택하면 바뀌는 영역 탐색이 시그니처.
학습한 제약: 완전 수직 탑뷰 금지. 45도에서 얼굴·손·바닥 깊이. 회의 때문에 업무 전체가 멈추지 않음. 승인 외형을 세련됨 명목으로 리디자인하지 않음. 매 단계 연구→아이디어→설계→검수.

2026-09-13 확장: 승인 외형·색감은 유지하고 실제 입체 탐색과 역할 모션을 추가한다. 먼지는 비등방 크기 변경 없이 둥근 비율, 다섯 단계는 서로 다른 이미지와 같은 입체 상태를 사용한다. 회전은 45도 시작·Y up 고정·고도20~75도이며 확대/축소와 좌우상하 회전을 지원한다. 공용 행동과 역할별 상태를 구분하고, 실제 실행/소리 인식을 연결했다고 말하지 않는다. 로딩 중에는 기존 시안을 보존한다.

2026-09-13 사용자 정정(v07): v06의 기능 통과는 자연스러운 연기·공간 품질을 증명하지 못했다. 일자 팔, 거의 읽히지 않는 표정, 단순한 도형 가구를 거부했다. 얼굴 변화와 전신 무게 이동을 연결하고, 실망해 이마 짚기·웅크려 서류 줍기·아빠다리·고뇌 같은 일상 연기를 구현한다. 45도와 근접의 연속 동작으로 판정한다. 공간은 이전의 곡선 구조와 지브리 생활감을 복원하고, 작업 도구·종이·직물·목재 결·창빛 등 실제 작업의 흔적을 세부까지 만든다. 소품 숫자만 늘리거나 화면 자동검사만 통과한 결과를 완성으로 선언하지 않는다.

2026-09-13 사용자 정정(v08): 5초 단일 동작이나 연구 문서는 최종 범위가 아니다. 사용자는 기술이 3D인지 영상인지보다 한 공간을 실시간으로 오래 볼 때 여러 캐릭터가 살아 움직이는 인상을 우선한다. 승인된 전체 공간의 디테일과 원본 외형을 보존하고, 동작이 동시에 시작하지 않는 비동기 장면·정지와 행동 사이의 moving hold·자연스러운 상태 전환을 별도 `living/` 화면에서 구현한다. 기존 3D 화면은 보존하되 새 경험의 주 화면으로 사용하지 않는다. 유료 5초 장면은 외형·접촉·반복을 검사하는 관문이며 전체 결과로 부르지 않는다.

2026-09-13 사용자 정정(v09): 기존의 밝은 원형 디오라마 공간은 폐기 대상이다. 그 이미지와 배치에 모션이나 소품을 더하는 방식으로 이어가지 않는다. 지브리 작품의 서재·공방·공동 작업 공간을 다시 조사하고, 캐릭터 없이 공간 구조부터 새로 만든다. 구조 통과 조건은 닫힌 실내, 전경·중경·배경, 두 층 이상의 높이 차, 원탁을 막지 않는 순환 동선, 창가 개인 책상, 별도 회의 공간, 제작대와 표본실이 한 장면에서 읽히는 것이다. 색과 소품만 바꾼 결과는 실패로 판정한다.

2026-09-13 구조 검수 정정(v10): 원탁이 있어도 바닥에 원형 단·링·받침을 만들지 않는다. 바닥은 한 장으로 이어지고, 원탁 좌석과 분리된 직통 통로가 실제 손잡이 문까지 보여야 한다. 창가 독서 책상과 제도·모형 제작 책상을 별개로 읽히게 하며, 회의실도 난간 장식이 아니라 출입문이 있는 방으로 증명한다. 정지 이미지 검수판은 최종 실시간 구현으로 간주하지 않고 독립 관문으로만 쓴다.

2026-09-13 살아 있는 공간 정정(v11): 승인된 공방은 한 장의 배경이 아니라 같은 고정물과 비율이 이어지는 좌·중앙·우·상부 시점으로 탐색한다. 드래그는 한 이미지 안의 제한 팬이고 시점 버튼은 실제 카메라 위치 전환으로 명확히 구분한다. 아침·낮·새벽·노을·비·눈·첫빛은 색 필터만 바꾸지 않고 창밖 밝기, 주광 방향, 실내등, 입자와 반사·그림자 방향을 한 상태로 묶는다. 소품은 장식 수가 아니라 읽기·제도·회의·수선·표본 보관의 작업 흔적과 손 닿는 위치로 배치한다. 캐릭터 확장은 루트 이동, 발 접촉 잠금, 골반 보정, 광원 연동 그림자를 먼저 통과시키고 얼굴·시선·몸짓을 성격별 행동표로 연결한다. 임시 접촉 리그의 통과를 최종 캐릭터 자연스러움으로 선언하지 않는다.
