# 역할과 공간 시뮬레이션

기존 공간 시안에 탐색 가능한 입체 공간을 추가했다. 실제 에이전트 실행 상태를 읽는 모니터가 아니라 역할·독립 작업·회의·인계를 구체화하는 예시다.

`living/`은 사용자 정정 이후 만든 별도 관찰 화면이다. 기존 입체 시안을 덮어쓰지 않고, 승인된 전체 공간을 그대로 둔 채 서재·원탁·창작 책상·먼지 작업대·관찰대의 영상 구역을 부드러운 마스크로 나눠 서로 다른 간격과 속도로 재생한다. 영상 사이에는 정지된 생각의 시간을 두고 같은 장면을 연속 재생하지 않아, 모든 인물이 기계처럼 동시에 반복하지 않게 한다. 움직임 정지와 시스템의 움직임 줄이기를 지원하며 모바일에서도 전체 공간 구도를 자르지 않는다.

`rebuild/`은 캐릭터를 배제하고 다시 설계한 연구 공방의 구조 검수판이다. `explore/`은 그 승인 공간을 중앙·왼쪽·창가 맞은편·상부·소품 근접의 다섯 시점과 아침·낮·새벽·노을·비·눈·첫빛의 일곱 환경 상태로 탐색하는 다음 관문이다. 중앙 시점은 일곱 상태마다 별도 실제 환경 플레이트를 쓰고 다른 각도는 합성 프리뷰로 표시한다. 드래그는 각 이미지 안의 제한 팬이며 자유 회전으로 설명하지 않는다. 임시 2D 접촉 리그는 모바일에서 의자를 관통해 공개 기능에서 제거했으며, 실제 캐릭터는 바닥 마스크·가구 가림·실제 리그 접촉 검증 뒤 배치한다.

`previs.html`은 승인된 아침 공방 위에 기존 3D 캐릭터 다섯을 합성한 동작 검수 화면이다. 하울의 다섯 키포즈, 캐릭터마다 다른 생활 리듬, 스스와타리의 짧은 보행과 서류 줍기, 발 접지 그림자와 가구 가림을 먼저 본다. 이 화면을 만드는 동안 Fal 유료 호출은 하지 않는다. 외형과 재질의 최종 교체는 동작이 통과한 뒤 별도 관문으로 남긴다.

- `node design/build.mjs` — 상위 agent-space 폴더에서 설치한 Three.js/esbuild를 사용한다.
- `python3 -m http.server 8794 --directory design` — 상위 폴더에서 실행한다. `file://`는 모델 로딩에 맞지 않는다.
- `node design/verify-previs.mjs` — 로컬 서버를 켠 뒤 다섯 캐릭터, 하울 다섯 키포즈, 비동기 상태, 스스와타리 이동, 3분 경계와 가까이 보기를 실제 브라우저에서 검사한다.
- 공개 파일은 메인 시뮬레이션과 `living/`, `rebuild/`, `explore/`, 그리고 각 화면이 참조하는 `assets/` 아래 산출물이다. 이 문서와 원본 모듈·연구 기록은 공개 묶음에서 제외한다.

`sim-src/geometry.js`가 곡면벽·책장·아치·피아노·작업대와 장애물 좌표를 만든다. 정적 가구는 재질별로 묶어 그리기 요청을 줄인다. `navigation.js`는 바닥 경계, 가구와 다른 담당자를 피해 경로를 찾는다.

`actors.js`는 하울의 생성 관절과 작은 캐릭터의 보정 관절을 움직인다. `dust.js`는 둥근 몸·눈·팔다리를 독립적으로 만든다. `expressions.js`는 작은 캐릭터의 기존 얼굴 위치에 맞춘 눈 깜빡임·시선·집중·궁금함·확인 후 미소를 그린다. 입 없는 캐릭터에 입을 추가하지 않는다. `surface.js`는 텍스처 경계의 번짐을 줄인다.

`main.js`는 정적 5단계의 단일 상태를 `space-phase`로 전달한다. 입체 장면은 대표 3명만 회의에 합류시키고 나머지 분신은 독립 작업을 이어간다. 정지·탭 숨김·공간 화면 밖에서는 시뮬레이션 시간을 진행하지 않는다. 움직임 줄이기는 처음부터 정지하며, 수동 단계 변경은 해당 배치를 즉시 보여 준다.

시점은 45도에서 시작하며 고도 15~70도, Y up 고정이다. 수평 회전은 자유롭다. 화면을 누른 뒤 휠, 터치 두 손가락, 방향키·+/−·Home과 버튼을 지원한다. 확대 창에서도 같은 장면과 조작 상태를 유지한다. 모델/그래픽 로딩이 실패하면 정적 시안으로 돌아갈 수 있다.

생성 출처·검수·비용은 연구 폴더 `260913-agent-space-motion`의 기록을 따른다. 공간 생성 GLB는 표면 결함으로 채택하지 않았다. 캐릭터의 자동 관절을 그대로 신뢰하지 않고 실제 크기·피부 가중치·표면·움직임을 화면에서 검수했다.


2026-09-13 연기·공간 개정: `acting.js`는 반응·동작·생각하는 정지·회복을 따로 조율한다. `rig.js`·`coat.js`는 팔꿈치·손목·무릎·코트 가중치를 보완하며 `face-shapes.js`는 실제 얼굴 표면을 변형한다. 사람의 홍채 크기는 고정하고 눈꺼풀만 열고 닫는다. 이마 짚기(하울), 고뇌(쿠로미), 서류 줍기·양반다리·독서(먼지), 발견(키티)의 6개 장면을 버튼으로 볼 수 있다. 양반다리 유지 중에는 호흡과 무게 이동이 이어지며, 단계가 바뀌면 앉은 자세를 먼저 풀고 이동한다.

`furnishings.js`·`materials.js`는 책의 비정형 쌓임, 상자·병·깃펜·종이 조각, 직물·창밖 풍경·식물·차 도구·다락 골조를 더한다. `rendering.js`는 접촉 음영과 부드러운 그림자를 만든다. 프레임이 지속적으로 느려지면 효과의 해상도·표본을 낮추고, 계속 느리면 접촉 음영을 끈다. 실제 폰의 성능은 검증하지 않았다.
