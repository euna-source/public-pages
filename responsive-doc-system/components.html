UI 에셋

작은 요소부터 같은 기준으로.

각 에셋은 실제 HTML입니다. 필요한 코드를 복사하고 내용만 바꿔 사용할 수 있습니다. 색과 조작 상태는 공통 스타일에서 관리합니다.

복사하기 전에시작 ZIP을 받은 뒤 공통 CSS·JavaScript를 함께 사용하세요. 같은 에셋을 한 페이지에 여러 번 붙이면 id, for, aria-describedby, data-copy의 연결 이름을 세트로 바꿔 중복을 피합니다.

단계와 타임라인

에셋 09

  1. 01 / 작성

    범위와 미결을 정리합니다.

    규칙마다 예외와 확인할 결과를 함께 씁니다.

  2. 02 / 검토

    구현·검증 가능한지 확인합니다.

  3. 03 / 공유

    승인 근거와 버전을 남깁니다.

    정본 링크와 바뀐 부분을 함께 안내합니다.
