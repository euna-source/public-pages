목록과 상세를 나누는 기준

목록에는 ID·이름·문구·현재 상태를 둡니다. 상세에는 조건·예외·연결 규칙·변경 이유를 둡니다. 중요한 예외가 여러 항목에 공통 적용되면 이 영역처럼 목록 위나 아래의 공통 규칙으로 노출합니다.

규모가 커졌을 때74개·198개처럼 많은 항목을 운영할 때는 전체/변경분 보기, 유형 필터, 안정된 항목 링크, 정렬과 상세 패널을 추가합니다. 이 키트는 검색 가능한 기본 구조이며 대규모 목록 성능 검증을 대신하지 않습니다.
