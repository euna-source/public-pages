규칙과 예외를 함께 읽기

REQ-01

공유 링크를 생성한다

정책 검토 중

소유자가 ‘링크 만들기’를 선택하면 공유 링크를 생성합니다. 이미 활성화된 링크가 있으면 같은 링크를 보여 줍니다. 생성 중에는 같은 요청을 중복으로 보내지 않습니다.

진입 조건
로그인한 사용자와 컬렉션 소유자가 같습니다.
완료 결과
링크 주소와 ‘링크 복사’ 버튼을 표시합니다.
오류 복구
실패 이유를 안내하고 다시 시도할 수 있게 합니다. 기존 링크는 지우지 않습니다.
예외 · 콘텐츠가 없는 컬렉션링크 생성 가능 여부는 아직 정하지 않았습니다. 임의의 동작을 구현하지 않고 아래 미결 항목에서 결정합니다.
REQ-02

공유 링크를 해제한다

정책 검토 중

소유자는 공유를 해제할 수 있습니다. 해제 전에는 기존 링크로 더 이상 열 수 없다는 결과를 확인합니다. 해제에 성공하면 링크 복사 기능과 공유 중 표시를 함께 제거합니다.

예외 · 해제 요청이 실패한 경우성공한 것처럼 화면을 바꾸지 않습니다. 공유 중 상태를 유지하고 재시도를 제공합니다.
REQ-03

받은 링크를 연다

정책 검토 중

활성화된 링크는 공유 대상 컬렉션을 보여 줍니다. 잘못되거나 해제된 링크는 원본 콘텐츠를 표시하지 않고 열 수 없는 이유와 돌아갈 경로를 안내합니다.

연결되는 결정로그인 없이 열람하게 할지는 미결 Q-01을 확인합니다.

상태에 따라 달라지는 화면

정상 화면만 그리면 요청이 실패하거나 정보가 없는 순간의 동작이 빠집니다. 각 상태에서 보이는 정보와 다음 행동을 같이 정의합니다.

공유 기능 상태와 독자의 다음 행동
상태 화면·다음 행동
요청 중 ‘링크를 만들고 있습니다’ 안내. 중복 실행을 막고 원래 버튼 문맥을 유지합니다.
성공 생성한 주소와 링크 복사를 표시합니다. 복사 결과는 텍스트로도 알립니다.
실패 ‘링크를 만들지 못했습니다. 다시 시도해 주세요.’ 기존 내용과 재시도 버튼을 유지합니다.
접근 불가 ‘이 링크로 컬렉션을 열 수 없습니다.’ 홈으로 이동하는 경로를 제공합니다.

구현 완료를 확인하는 기준

아래 체크는 페이지를 새로 열면 초기화됩니다. 실제 검증 결과는 팀의 정본 문서에 기록합니다.
