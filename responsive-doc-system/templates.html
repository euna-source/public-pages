문서 템플릿

목적에 맞는 구조를 고르세요.

공통 머리말로 맥락을 맞추고, 본문은 읽는 사람의 과업에 따라 다르게 구성합니다. 모든 예시는 실제로 열고 수정할 수 있는 HTML입니다.

01

의사결정안

방향이나 정책을 정할 때

결정할 것 → 근거 → 대안·추천 → 영향 → 미결

예시 열기
02

기능 명세

동작과 예외를 개발자에게 전달할 때

범위 → 규칙·예외 → 상태 → 인수 조건 → 미결

예시 열기
03

운영 타임라인

기간과 역할에 따라 실행할 때

전체 순서 → 단계별 조건·담당 → 예외 → 확인

예시 열기
04

문구·항목 목록

여러 항목 중 특정 내용을 찾을 때

검색 → 요약 목록 → 조건·문구·예외 상세 → 이력

예시 열기
05

QA·변경 보고

문제를 재현하고 수정 결과를 확인할 때

영향 → 환경 → 재현 → 실제·기대 → 검증·근거

예시 열기

서로 다른 목적이 함께 있을 때

전체 방향을 정하는 문서 안에서 특정 기능을 설명해야 한다면 의사결정안을 기본으로 하고 기능 명세를 연결합니다. 하나의 거대한 페이지에 모든 상세를 반복해서 넣지 않습니다.

고정하는 부분

문서 목적, 현재 상태, 이번에 확인할 것, 담당·버전·정본, 다음 행동.

조합하는 부분

비교표, 규칙·예외, 문구 목록, 단계, 인수 조건, 변경 이력. 없는 내용은 빈 칸으로 남기지 않습니다.

파일로 가져가서 시작하기

ZIP을 풀고 원하는 template-*.html을 복사하세요. 내용은 HTML에서 편집하고, 공통 디자인은 system.css에서 관리합니다. 비개발자를 위한 시각 편집기는 포함하지 않습니다.
