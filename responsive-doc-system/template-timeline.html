시점 단계·종료 조건
D−7 ~ D−4 후보 확인 · 추천 대상과 제외 사유 기록
D−3 ~ D−1 내용 검수 · 공개 동의와 소개 내용 확인

단계마다 누가 무엇을 확인하는가

  1. D−7 ~ D−4

    후보를 확인합니다.

    운영 담당이 추천 조건과 제외 조건을 대조합니다. 진입 조건은 추천 기준의 확정이며, 종료 조건은 후보별 확인 근거가 기록된 상태입니다.

    담당 역할: 운영 · 실제 담당자 미정

  2. D−3 ~ D−1

    공개할 내용을 검수합니다.

    소개 문구·이미지·링크와 공개 동의를 확인합니다. 미확인 항목이 있는 대상은 공개 대기 상태로 구분합니다.

    담당 역할: 운영·콘텐츠 검수 · 실제 담당자 미정

  3. D0

    공개 결과를 확인합니다.

    대상·순서·이미지·링크가 승인된 내용과 같은지 확인합니다. 공개 작업 성공과 화면 검증 통과를 별도로 기록합니다.

    담당 역할: 운영·QA · 실제 담당자 미정

  4. D+1 ~ D+3

    문의와 수정 이력을 정리합니다.

    공개 이후 변경에는 이유와 적용 시점을 남깁니다. 다음 운영에 영향을 주는 문제는 기준 수정 후보로 분리합니다.

    담당 역할: 운영 · 실제 담당자 미정

일정이 계획대로 진행되지 않을 때

동의 확인 지연해당 대상만 대기할지 전체 공개를 미룰지 사전에 정해야 합니다. 이 예시에서는 결정하지 않았습니다.
공개 실패실패 범위와 현재 노출 상태를 먼저 확인합니다. 중복 공개되지 않도록 재실행 조건과 복구 담당을 정합니다.
