이번에 정할 것

공유 링크의 기본값을 ‘로그인 후 열람’으로 제안합니다. 다만 공개 홍보가 주된 사용 목적이고 노출 위험을 충분히 통제할 수 있다면 로그인 없는 열람이 더 적합할 수 있습니다.

판단에 필요한 근거

확인할 사용자 상황
작업물을 빠르게 보여 주려는 사람과 공개 범위를 제한하려는 사람이 같은 기능을 사용합니다.
확인한 자료
이 예시는 실제 조사 결과를 포함하지 않습니다. 인터뷰·열람 흐름·권한 정책을 연결할 자리입니다.
핵심 가정
초기에는 접근 편의보다 공개 범위의 예측 가능성을 우선합니다. 이 가정은 검증이 필요합니다.

선택지와 선택 기준

두 선택지의 차이 · 가상 제안
기준 로그인 후 열람 로그인 없이 열람
접근 편의 로그인 과정이 필요합니다. 링크에서 바로 볼 수 있습니다.
공개 범위 계정 접근 정책을 적용할 수 있습니다. 링크 재공유와 노출 범위를 검토해야 합니다.
추가 확인 로그인 이탈과 복귀 흐름 검색 노출·미리보기·콘텐츠 보호
추천이 바뀌는 조건실제 주 사용 목적이 외부 홍보이고, 로그인 단계가 핵심 과업을 막는다는 근거가 확인되면 기본 공개 범위를 다시 검토합니다.

이 결정이 바꾸는 것

  • 공유 링크의 열람·오류 화면과 로그인 복귀 경로
  • 컬렉션 소유자에게 공개 범위를 설명하는 문구
  • 개발·QA의 권한과 접근 불가 검증 범위
