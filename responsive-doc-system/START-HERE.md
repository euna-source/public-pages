# 문서 디자인 시작 키트 · v0.3

## 시작하기

1. ZIP을 폴더에 풉니다. `index.html`을 열면 전체 가이드를 볼 수 있습니다.
2. `template-decision.html`, `template-spec.html`, `template-timeline.html`, `template-copy.html`, `template-qa.html` 중 목적에 맞는 파일을 복사합니다.
3. 복사한 HTML에서 제목, 요약, 상태, 본문, 버전, 담당 역할, 정본 링크, 변경 이력을 실제 내용으로 바꿉니다. 정책의 미결을 임의로 채우지 않습니다.
   문서 유형과 무관한 상태는 ‘해당 없음’과 이유를 적습니다. 운영 문서의 실행 여부처럼 필요한 상태는 따로 추가합니다.
4. 공통 디자인은 `system.css`, 공통 조작은 `system.js`, 첫 화면 테마는 `theme-init.js`에서 관리합니다. 이 파일과 글꼴을 HTML과 같은 폴더에 둡니다.
5. `components.html`에서 필요한 에셋의 코드를 복사해 붙입니다. 같은 에셋을 여러 번 사용하면 연결된 ID를 모두 바꿉니다.
6. 라이트·다크, 좁은 화면, 키보드, 긴 내용, 검색 빈 결과, 오류·복사 실패, 인쇄를 확인합니다.

별도 빌드가 필요하지 않습니다. 내용을 바꾸려면 HTML 편집이 필요합니다. 비개발자를 위한 시각 편집기나 Figma 라이브러리는 포함하지 않습니다.

## 파일

- `index.html`: 시작 가이드
- `foundations.html`: 색상, 서체, 위계, 강조, 여백, 반응형
- `components.html`: 16개 UI 에셋 그룹과 복사 코드
- `templates.html`: 문서 유형 선택
- `writing.html`: 작성·검수·운영 기준과 출처
- `template-*.html`: 수정 가능한 문서 예시 5종
- `system.css`: 두 테마의 의미 토큰과 공통 스타일
- `theme-init.js`, `system.js`: 테마, 검색, 복사, 대화상자, 인쇄 처리
- `PretendardVariable.woff2`, `FONT-LICENSE.txt`: 로컬 글꼴과 SIL OFL 라이선스

## 공개 전에

모든 템플릿은 가상 예시입니다. 실제 정책으로 오해되지 않도록 상태와 출처를 바꿔 주세요. 개인정보, 미공개 내용, 내부 경로, 접근 토큰이 없는지 확인하세요. 정본 링크는 팀의 실제 문서 위치로 연결합니다. 키트의 C8 표식은 문서용 식별자이며 새 공식 로고를 제안하는 것이 아닙니다.

## 동작 범위

테마 선택은 브라우저 저장소를 사용합니다. 시스템 설정을 기본으로 하며, 저장이 차단되어도 현재 화면에서 전환할 수 있습니다. 파일로 직접 열 때 저장소 동작은 브라우저에 따라 다를 수 있습니다. 검색어는 현재 URL에 남지만 서버에 전송하는 검색 API는 없습니다.

자동 복사는 HTTPS 또는 브라우저가 허용하는 환경에서 동작합니다. 차단되면 내용을 선택하고 수동 복사를 안내합니다. 체크리스트와 예시 입력은 서버에 저장하지 않습니다.

새로 만든 HTML에서도 공통 파일과 글꼴의 상대 경로가 유지되어야 합니다. 단일 HTML만 다른 곳으로 옮기면 스타일·글꼴·조작이 누락됩니다. 공유할 때는 폴더 전체를 배포하세요.

실기기·Safari·스크린리더와 실제 개발자의 문서 이해도 검증은 별도로 진행하세요. 이 키트는 제품의 전체 접근성 인증이나 권한·저장·협업 기능을 제공하지 않습니다.

## 문서 밀도

업무 검토 문서는 데스크톱 본문 15px·제목 28px·절 제목 20px, 모바일 본문 16px·제목 24px를 출발점으로 사용합니다. 긴 해설문과 업무 명세를 구분하며, 18px 본문이나 큰 히어로를 모든 문서에 강제하지 않습니다. 동일 화면 폭·100% 확대에서 실제 규칙과 예외를 함께 볼 수 있는지, 200% 확대와 320px에서도 내용이 보존되는지 확인합니다. 값은 접근성 표준의 의무 크기가 아니라 이 키트의 설계 선택입니다.
