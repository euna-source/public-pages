기초 규칙

차분한 바탕, 분명한 위계.

색은 역할을, 글자는 읽는 순서를, 여백은 정보 사이의 관계를 표현합니다. 모드가 바뀌어도 의미와 강조 순서는 같습니다.

무드컬러타이포그래피강조구조·여백반응형

무드: 정돈된 편집과 정확한 인터페이스

밝은 화면은 흰 종이와 옅은 회녹색 바탕, 어두운 화면은 차콜 바탕과 한 단계 밝은 표면으로 구성합니다. 서체는 한 가지로 유지하고, 굵기와 크기의 차이로 문서의 표정을 만듭니다.

C8의 밝은 그린은 작은 브랜드 표식에 남깁니다. 본문 링크에는 모드별로 읽기 쉬운 그린을 사용합니다. 사진·그라디언트·큰 색 면은 문서의 내용보다 앞서지 않게 절제합니다.

색상의 역할

HTML마다 새 색을 고르지 않고 --text, --surface, --accent처럼 의미가 있는 토큰을 씁니다. 아래 두 표본은 현재 테마와 관계없이 각 모드를 보여 줍니다.

상태 색은 별도의 언어입니다그린=완료·긍정, 앰버=검토·주의, 레드=오류·위험, 블루=참고. 색만으로 구별하지 않고 상태 이름과 이유를 함께 씁니다. 전체 의미 색은 알림 에셋에서 확인할 수 있습니다.
테마 전환의 기본 동작첫 방문은 시스템 설정을 따릅니다. 직접 선택하면 이 브라우저에 저장합니다. ‘시스템’을 다시 선택하면 운영체제 변경을 따라갑니다. 저장이 차단되어도 현재 페이지의 전환은 동작합니다.

대비와 표면

일반 텍스트 대비는 최소 4.5:1, 큰 글자는 3:1을 기준으로 검사합니다. 입력 경계·필수 상태 표시도 배경과 3:1을 목표로 합니다. 구분선은 조작부 경계와 다른 약한 색을 씁니다. 다크 모드에서는 그림자를 짙게 쌓기보다 표면 밝기와 경계로 층을 구분합니다.

가독성을 지키는 세부 규칙

  • 긴 본문 폭은 최대 38rem입니다. 글자 수를 고정하지 않고 실제 문장으로 줄 길이를 확인하며, 표와 목록은 내용에 맞게 더 넓게 씁니다.
  • 본문 자간은 0입니다. 한국어의 단어 경계는 유지하되 긴 URL·식별자는 줄바꿈을 허용합니다.
  • 핵심 규칙은 14px 보조 글자로 내리지 않습니다. 보조 색도 실제 표면에서 대비를 검사합니다.
  • 제목은 h1 한 개, h2 주요 묶음, h3 하위 주제 순으로 씁니다. 크기를 맞추려고 제목 수준을 건너뛰지 않습니다.
  • 표의 숫자는 동일 폭 숫자를 사용합니다. 숫자 비교 열은 오른쪽, 문장은 왼쪽 정렬합니다.

적용 예시

링크를 해제하면 기존 링크로 컬렉션을 열 수 없습니다. 콘텐츠 자체는 삭제되지 않습니다.

피해야 할 방식

모든 문장을 굵게, 빨갛게, 밑줄로 동시에 강조하면 읽는 순서가 사라집니다. 경고 색을 단순한 중요 표시로 쓰지 않습니다.

화면과 여백의 위계

공통 화면 틀

현재 문서와 테마 설정을 위쪽에, 이동 경로를 왼쪽에 둡니다. 본문은 목적과 요약으로 시작하고, 내용을 읽은 뒤 필요한 행동으로 끝납니다.

문서 폭은 최대 1120px 안팎, 본문은 38rem을 기준으로 합니다. 넓은 화면을 빈 카드로 채우지 않습니다.

화면 폭에 따른 정보 배치

반응형 규칙과 유지해야 하는 의미
정보 유형 좁은 화면에서의 규칙
탐색·머리말 1040px 이하에서 왼쪽 탐색을 상단 ‘가이드 목차’로 옮깁니다. 640px 이하에서는 고정 헤더를 해제해 읽는 공간을 확보합니다.
본문·상태 본문은 데스크톱 15px, 좁은 화면 16px를 사용합니다. 요약·정책·구현·검증 상태는 숨기지 않고 줄바꿈합니다.
비교·정의 긴 설명은 이름과 값을 한 묶음으로 쌓습니다. 두 대상을 번갈아 비교해야 하면 같은 속성 단위로 묶습니다.
숫자 표 열 관계가 의미인 표만 내부 가로 스크롤을 허용합니다. 표 제목·헤더·스크롤 안내·키보드 접근을 유지합니다.
시간·순서 단계의 순서·기간·담당을 함께 유지합니다. 달력 자체가 중요한 경우 날짜를 문장으로만 바꾸지 않습니다.
조작·오버레이 조작 영역은 내부 기준 44px 이상. 대화상자는 화면 안에 맞추고 키보드·닫기·초점 복귀를 확인합니다.

320px 리플로우와 확대를 별도로 검사합니다. 복잡한 2차원 표의 예외는 WCAG Reflow 기준에 맞춰 판단합니다. 44px은 이 키트의 조작 기준이며 WCAG 2.2 AA 최소 타깃 기준과 동일한 수치가 아닙니다.
