01결론

아홉 구간에 주인공 하나씩, 영상은 둘이에요

홈 v0.10 열세 구간 중 아홉에 주인공 모션을 하나씩 두고, 넷은 움직이지 않아요. 영상은 리스펙트 녹화와 1분 이야기 미리보기 둘이고, 나머지는 코드예요.
  • 토큰. M3 Expressive 여섯 값 중 눈에 보이게 튕기는 건 spatial.fast(9%) 하나예요. 그래서 effects 셋과 spatial.fast는 M3 그대로 두고, spatial.default·slow만 튕김 없이 빨리 멈추는 값으로 바꾸는 C안을 권해요. 세 후보는 비교 화면에서 폰으로 눌러 볼 수 있어요.
  • 원칙. 리서치 권장 그대로 가요. 구간마다 주인공은 하나, 작품 위에는 effects만, 튕김은 C8 버튼·로고만이에요.
  • 배분. 실제 화면 녹화와 영상 콘텐츠만 영상으로 두고, 둘 다 포스터를 먼저 깔고 멈춤 버튼을 달아요. 실사 촬영 장면은 지금 홈에 없어요.
02기준

장면은 v0.10 열세 구간이고, 앞선 결정 셋을 지켜요

리서치는 v0.7을 상위 문서로 적었지만 홈은 v0.8·v0.9를 거쳐 v0.10(10/25)이 최신이에요. v0.7의 핀 고정 장면은 지금 홈에 없고 1분 이야기 영상 안으로 들어갔어요.

앞선 결정 어디서 이번 기획에 미치는 것
스크롤 연출은 내려놓는다 v0.8 제안, v0.9 권장 토스식 '스크롤 = 재생 바'와 플립북은 안 써요
첫 화면은 카드가 한 번 올라오는 움직임 하나 v0.9.1 1번 주인공이 정해져 있어요
05장 스크롤 따라 넘김은 뺀다 v0.10 9번은 누를 때만 움직여요

토스에서는 둘만 가져와요. 영상은 보일 때만 돌리고, 앞 장면 물건이 뒷장면 입구가 돼요(1번 예시 카드와 11번 미리보기 카드가 같은 모양·같은 토큰). 토스가 안 하는 '움직임 줄이기' 존중은 우리가 해요.

03모션 토큰

여섯 값 중 튕기는 건 하나뿐이에요

레인이 원문으로 확인한 M3 Expressive 값을 계산해 봤어요. 튕김은 목표를 넘는 정도, 멈춤은 목표의 0.5% 안에 들 때까지의 시간이에요(질량 1).

spatial.slow 200 / 0.8 22.6 1.5% 0.54초
effects.fast 3800 / 1.0 123.3 0 0.16초

default·slow의 1.5%는 40px 움직일 때 0.6px라 눈에 거의 안 보여요. '안드로이드 느낌'은 튕김보다 0.4~0.54초의 느긋한 길이에서 와요. 튕김 없는 effects 셋은 그대로 두고 spatial 셋만 견줘요.

C안은 '튕김은 버튼·로고만' 원칙과 값이 그대로 맞아요. B안이면 튕길 곳이 없어져요. 비교 화면에서 셋을 나란히, 느리게도 볼 수 있어요.

값은 motion-tokens.json 한 파일(DTCG 형식, 스프링은 $extensions)에 두고 CSS·motion·GSAP 값을 뽑아요. 와이어의 0.22·0.3·0.5초 전환도 이 토큰으로 바꾸고, 릴스는 자막 규칙과 엔딩 로고 값을 같은 파일에서 가져가요.

04장면별 주인공 모션

아홉 구간에 하나씩, 넷은 멈춰 있어요

토큰은 C안 기준이고, '코드'는 motion 또는 CSS 전환이에요. 2번(폴더 그림은 v0.10 결정대로 멈춘 그림)·3번 기능 머리·10번 길 찾기·13번 푸터는 움직이지 않아요.

# 구간 주인공 모션 토큰 영상/코드 움직임 줄이기 대체
1 첫 화면 예시 카드가 아래에서 24px 한 번 올라와요. 처음부터 보이는 상태로 위치만 움직여 첫 화면 2.5초를 지켜요 spatial.slow 코드 제자리에 멈춘 카드
4 01 올리기 고른 항목에 맞춰 폰 화면이 '고르기 → 올림 완료'로 바뀌어요. 폰 틀은 그대로예요 effects.default 교차 페이드 코드(화면은 정지 이미지) 바로 바뀜
5 02 리스펙트 리스펙트 녹화 12.4초가 소리 없이 반복돼요 영상 위 모션 없음 영상 자동재생 없이 끝 장면 포스터와 재생 버튼
6 03 프로필 링크 하나가 프로필 한 장으로 펼쳐져요. 카드 틀만 움직이고 안의 작업 칸은 페이드로 들어와요 spatial.default + effects.default 코드 펼친 상태로 보임
7 04 노크 노크 첫 메시지 말풍선이 한 번 들어와요 spatial.default 코드 말풍선이 처음부터 보임
8 다리 '300자, 다 채웠을까요?'가 어절 단위로 한 번 올라와요. 릴스 자막과 같은 규칙이에요 spatial.default + effects.fast, 어절 시차 40~60ms(시안 뒤 확정) 코드 문장이 한 번에 보임
9 05 1분 이야기 대표 편 포스터 위에서 6~8초 무음 미리보기가 돌아요. 누르면 소리를 켜고 1분 전체가 나와요 미리보기 위 모션 없음 영상 포스터와 '소리 켜고 보기'
11 내 프로필 미리보기 고른 하는 일과 쓴 이름이 미리보기 카드에 바로 들어가요(누른 뒤 0.2초 안). 1번 카드와 같은 모양이에요 effects.fast(글자), 390 결과 창은 spatial.default 코드 바로 바뀜
12 FAQ·끝 문장 끝 문장이 보이면 C8 로고가 한 번 튕겨요. 릴스 엔딩 로고와 같은 값이에요 spatial.fast 코드 멈춘 로고

옆으로 밀어 보기 →

어디서나 같은 사용자 반응은 주인공 수에 넣지 않아요. 버튼 누름은 spatial.fast(크기 0.96 → 1), 항목 열기는 높이는 바로 열고 내용만 effects.fast, 칩·목차 표시는 effects.fast, 상단·하단 바는 spatial.default, 선반 타일은 effects.fast 밝기예요. 움직임 줄이기면 모두 바로 바뀌어요.

05영상과 코드 나누기

영상은 둘, 나머지는 코드예요

영상은 실제 앱 화면 녹화(5번)와 영상 콘텐츠 자체(9번)만이에요. 둘 다 다음을 지켜요.

  • 포스터가 완성된 화면이에요. iOS 저전력 모드는 무음 영상 자동재생도 막아요. 5번 포스터는 알약이 지나간 뒤 GOAT와 초록 별이 남은 끝 장면, 9번은 대표 편 포스터예요.
  • 멈춤 버튼을 달아요. 5번은 12.4초, 9번 미리보기는 6~8초라 둘 다 5초를 넘어요(WCAG 2.2.2).
  • 보일 때만 돌아요. 화면 1,200px 앞에서 불러오고, 보일 때 재생하고, 벗어나면 멈춰요(토스 방식).
  • 자동재생이 막히면 재생 버튼을 보여 줘요. 포스터만 덩그러니 남지 않게 해요.
  • 용량. 5번은 1MB 안이 목표예요(v0.10, 아직 안 쟀어요). 9번 미리보기도 같은 기준으로 재요.

나머지 일곱 구간은 코드예요. HyperFrames 원본은 홈에 심지 않고(iframe 엔진·라이선스 표기), 필요하면 mp4로 렌더해 넣어요. 실사 촬영 장면이 생기면 6~8초 무음 루프와 포스터로 넣어요.

06원칙과 버린 것

여섯 줄로 정하고, 여섯 가지는 버려요

  1. 구간마다 주인공 모션은 하나예요. 나머지는 누르거나 열 때만 반응해요.
  2. 작품(썸네일·포스터·영상) 위에는 effects만 써요. 작품의 크기나 위치는 튕기지 않아요.
  3. 튕김(spatial.fast)은 C8 버튼과 로고에만 써요.
  4. 스크롤에 묶지 않고, 화면에 들어올 때 한 번이나 누를 때만 움직여요.
  5. transform과 opacity만 움직여요. 높이 애니메이션과 transition: all은 안 써요.
  6. 움직임 줄이기가 켜지면 위치·크기 움직임은 끄고 투명도만 남겨요. 영상은 포스터와 재생 버튼이에요.

버리는 것은 스크롤 고정·스크럽 재생과 플립북(앞선 결정, 장면당 소재 90~144장), 부드러운 스크롤 라이브러리, 자동 넘김·마키(v0.9), 구간마다 같은 페이드업(AI 티), 아코디언 높이 애니메이션(저사양 위험), 작품 확대·튕김이에요.

07반론과 뒤집힐 조건

가장 큰 걱정은 '밋밋하다'예요

반론 지금 판단 뒤집힐 조건
넷이 안 움직이면 홈이 밋밋해요 2번은 문장, 3·10·13번은 짧은 길목이라 움직임이 오히려 방해예요 사람 시험에서 '심심하다'가 절반을 넘으면 8번 같은 어절 등장을 2번 문장에도 써요
C안은 두 체계를 섞어서 '왜 이 값'을 설명하기 어려워요 '튕김은 버튼·로고만'이라는 원칙 하나로 설명돼요 비교 화면에서 A안이 더 C8답게 느껴지면 A안으로 가요
영상이 둘뿐이면 저사양 폰에서 코드 장면이 버벅일 수 있어요 transform·opacity만 써서 위험이 낮아요 저사양 안드로이드 실기기에서 긴 프레임이 잦으면 그 구간만 영상으로 바꿔요
계산한 멈춤 시간이 실제와 달라요 motion과 Compose는 멈춤 판정이 달라요. 표는 출발값이에요 웹과 릴스를 나란히 놓고 체감이 다르면 웹 쪽 값을 맞춰요

확인 전

멈춤 시간은 계산값이고, 비교 화면은 웹만이에요. 릴스에 같은 값을 넣은 렌더는 아직 없어요. 4·6·7번 폰 화면 이미지가 11/2 빌드 화면과 같은지, 영상 둘의 실제 용량도 아직 안 쟀어요.

08정할 것

샐리가 정할 것은 셋이에요

01스프링은 어느 후보로 갈까요?

권장: C안이에요. effects 셋과 spatial.fast는 M3 그대로, spatial.default·slow만 Standard 값(700/0.9·300/0.9)으로 바꿔요. 비교 화면에서 셋을 눌러 보고 정하면 돼요. 릴스 쪽 나란히 대조는 확정 뒤 나나가 해요. 뒤집힐 조건: A안이 더 C8답게 느껴지면 A안이에요.

02모션 원칙 여섯 줄을 그대로 쓸까요?

권장: 그대로 써요. 구간마다 주인공 하나, 작품 위엔 effects만, 튕김은 버튼·로고만이에요. 뒤집힐 조건: 사람 시험에서 '심심하다'가 절반을 넘으면 주인공 수는 그대로 두고 2번에 어절 등장을 더해요.

03영상은 리스펙트 녹화와 1분 이야기 미리보기 둘만 둘까요?

권장: 둘만 둬요. 나머지 일곱 구간은 코드예요. 뒤집힐 조건: 저사양 실기기에서 코드 장면이 영상보다 거칠면 그 구간만 영상으로 바꿔요.
