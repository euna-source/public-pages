활동명과 사용자 ID는 무엇이 다른가요?

활동명은 창작 활동에서 자신을 소개할 때 사용하는 이름이나 닉네임이고, 사용자 ID는 계정마다 부여되는 고유한 식별 이름이에요.

  • 활동명: 실명이 아니어도 되고, 다른 크리에이터와 같아도 돼요. 2~8자로 한글·영문·숫자만 쓸 수 있고, 공백과 특수문자는 쓸 수 없어요. 활동명은 항상 공개되며, 공개 범위를 따로 설정할 수 없어요.
  • 사용자 ID: 다른 크리에이터와 겹칠 수 없어요. 2~13자로 영문 소문자·숫자·마침표(.)·밑줄(_)만 쓸 수 있어요. 프로필 주소와 검색에 쓰여요.

ID를 바꾸면 14일 동안 다시 바꿀 수 없어요. 이전 ID로 만든 프로필 링크는 새 프로필로 이어지지 않아요. 이전 ID는 14일 동안 다른 크리에이터도 쓸 수 없어요.

※ 활동명과 ID는 한 번 입력하면 비워 둘 수 없어요. ID의 처음과 끝에는 마침표를 쓸 수 없고, 마침표를 연속해서 쓸 수도 없어요. 욕설이나 정책에 어긋나는 단어는 활동명과 ID 모두에 쓸 수 없어요.
